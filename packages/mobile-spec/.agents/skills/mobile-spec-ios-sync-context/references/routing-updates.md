# iOS 路由回写

仅在候选涉及组件 AGENTS、业务线 Index、根 AGENTS 或跨 Pod 路由时读取。

## 组件 AGENTS

只有新增/改名/迁移/拆分上下文文档、关键词无法命中、摘要会导致误读或出现高频新业务域时更新。只写使用方式、路由表、必读上下文和冲突处理，不写业务细节。

## 业务线 Index

只有覆盖 Pod、业务线流程文档、可直接路由的子上下文、路径/摘要或跨 Pod 联读关系变化时更新。只写覆盖 Pods、入口、阅读顺序、子文档索引和摘要。

## 根 AGENTS

仅在新增业务线、全局 Pod 定位、全局依赖边界或全局提交/Pods/OnePods 规则变化时更新。

## 确认

路由类候选必须展示文件、级别、路由变化与原因，并要求用户确认执行范围。路由不命中时不新建、不猜测。
