# Cooper PRD 源

仅在生成或修订 artifact 且已获得 Cooper PRD 链接时读取；链接可由用户直接提供，也可从望岳需求获得。

1. 已安装且可用 `cooper` skill 时读取文档正文，只提取需求相关的背景、目标、范围、行为和验收。
2. skill 缺失、读取失败或无权限时，保留原链接和失败原因；已有文本来源足以确定范围和验收时继续，否则要求用户提供导出正文或粘贴正文。
3. 正文包含望岳链接或 `R-WYC-*` / `WYC-*` 时记录望岳 ID；仅在 `ddp` 可用时补充负责人，补充失败不阻断，但记录缺失字段和原因。
4. 正文中的技术方案、接口文档、其他实现方案或设计稿链接只登记原始链接和材料类型，不打开或读取链接目标；正文中直接提供的设计稿截图必须读取，作为 PRD 改动点的样式补充，样式以截图为准，文案和逻辑以 PRD 为准。
5. 记录 `preferredCapability`、`actualReadPath`、失败原因、已获取字段和未获取字段。
6. 所有可用来源合并后仍缺少会改变范围或验收的核心事实时停止；用户在当前会话明确提供的自然语言文本本身是合法需求来源。
