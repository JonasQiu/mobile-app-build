# URL 需求源

仅在生成或修订 artifact 且用户提供 HTTP(S) 链接时读取。

1. 使用当前环境可用的标准网页或文档读取能力，只提取与本次需求有关的背景、目标、范围、行为和验收事实。
2. 链接无法访问、需要登录或读取失败时，保留原链接和失败原因；已有文本足以确定范围和验收时继续，否则请用户粘贴或导出正文。
3. 页面中的其他技术方案、接口文档或设计稿链接只登记类型和 URL，除非用户明确将其作为本次输入。
4. 记录实际读取路径、已获取字段、未获取字段和内容摘要，来源统一映射为通用 URL 元数据。
5. 多个来源冲突且会改变范围或验收时，写入未决问题并停止 ready，不静默选择任一来源。
