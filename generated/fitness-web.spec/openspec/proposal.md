# 提案：健身俱乐部官网（fitness-web）

## 一句话需求
做一个健身网站。

## 背景与目标
构建一个面向城市白领与健身爱好者的现代化健身俱乐部品牌官网。网站需要传达专业、
活力、高端的品牌调性，承担"品牌展示 + 课程介绍 + 教练展示 + 课表查询 + 会员转化 +
到店预约"的完整闭环，让访客在几分钟内完成"了解—信任—留资"的转化路径。

## 目标用户
- **主用户**：25–40 岁城市白领，工作日下班后锻炼，重视体态、减脂、压力释放。
- **次用户**：健身进阶爱好者，关注力量训练、搏击、功能性训练。
- **新用户**：健身零基础、有意愿但尚未入门的人群，需要低门槛引导与教练背书。

## 主要版块
1. **首页（Home）**：英雄区 + 数据带 + 精选课程 + 为什么选择我们 + 学员口碑 + 转化 CTA。
2. **训练课程（/courses）**：按"力量 / 有氧 / 柔韧 / 搏击"分类筛选课程卡片。
3. **教练团队（/trainers）**：教练头像、擅长方向、从业年限、个人简介。
4. **周课表（/schedule）**：按周一~周日切换查看每日课程安排（时间 / 课程 / 教练 / 教室）。
5. **会员价格（/membership）**：月付/年付切换、三档会员套餐、常见问题 FAQ。
6. **联系 / 预约（/contact）**：留资表单（姓名 / 手机 / 意向课程 / 期望时间 / 备注）+ 场馆信息。

## 非目标（本期不做）
- 不做后端、不做真实登录与支付。
- 不做会员中心、订单、CMS 等运营后台。
- 不做后台数据可视化（仅前端展示）。

## 成功标准
1. 6 个页面全部可访问，导航与活动链接状态正常。
2. 所有交互（筛选 tab、价格切换、表单提交、FAQ 折叠、BMI 计算）为真实可用组件，
   无占位、无"敬请期待"。
3. 视觉风格统一、深色 + 青柠绿（#a9ff57 系）活力主题，移动端优先、响应式良好。
4. 全站文案为简体中文，价格、时间、教室、人名真实可信。
5. `npm run build` 通过，无 error / warning。
