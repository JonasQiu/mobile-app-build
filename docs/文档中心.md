## 自动文档流程

每次非 `[docs-sync]` push 后，GitHub Actions 运行 `scripts/sync-docs.mjs` 与 `scripts/check-docs.mjs`。实现状态快照记录本次源提交 SHA，因此 Actions 会创建一个带 `[docs-sync]` 标记的后续文档提交并推回同一分支；该标记阻止递归执行。

叙述性设计变更仍需人工更新对应文档；自动流程负责事实快照、链接、过时状态和敏感值门禁。

## 维护规则

- 修改 API 或 Runner 状态字段时，同时更新 [API 与事件协议](API与事件协议.md)。
- 修改用户流程时，同时更新 [MVP 产品说明](MVP产品说明.md)。
- 修改部署与 Secret 时，同时更新 [安全与运维方案](安全与运维方案.md) 和 [开发、验证与部署手册](开发验证与部署手册.md)。
- 文档不得记录真实密码、API Key、Runner token、Session token 或 Sites bypass token。
- Quick Tunnel 不得描述为生产部署或稳定交付。
