# 安全与运维方案

## 1. 当前安全边界

- OpenAI Sites 使用 owner-only 访问策略；应用内部另有 MVP 账号 Session。
- 密码使用 PBKDF2-SHA256、独立 salt 与迭代次数；Cookie 为 HttpOnly、Secure、SameSite=Lax。
- Runner `/jobs` 创建与查询都需要 `CODEX_RUNNER_TOKEN`。
- Runner callback 使用独立 `RUNNER_CALLBACK_TOKEN`；当前线上以控制站主动拉取为主。
- Codex CLI 结构化调用使用 ephemeral、read-only sandbox，不允许 `dangerously-bypass`。
- 生成文件必须通过路径、扩展名、路由和必需文件校验。
- 浏览器不能写终态，只有服务端验证三项 evidence 与 URL 后写入 D1。

## 2. Secret 管理

以下值只能存在于托管环境变量或本机受限临时环境，不得提交：

- `CODEX_RUNNER_TOKEN`
- `RUNNER_CALLBACK_TOKEN`
- `OPENAI_API_KEY`
- Sites bypass token
- DeploymentProvider token
- Session cookie/token

日志、错误、文档、截图和 Git remote 均不得包含明文 Secret。文档自动检查会扫描常见 Key、Bearer、私钥和环境赋值模式，但不能替代人工审查。

## 3. 当前运行风险

| 风险 | 当前控制 | 剩余问题 |
|---|---|---|
| 浏览器伪造交付 | PATCH 403 + 服务端 evidence | 需持久审计事件 |
| Prompt 注入写文件 | 固定 system contract + Zod + 安全路径 | 需更强内容/依赖策略 |
| Runner 被未授权调用 | Bearer token + 定长比较 | 临时公网入口仍扩大攻击面 |
| Secret 泄漏 | 环境变量、文档扫描、错误裁剪 | 需集中 Secret manager 与轮换 |
| 构建依赖风险 | lockfile + `npm ci` | 当前网络策略未隔离到 allowlist |
| 重复任务 | projectId 幂等 | Runner 重启后幂等状态丢失 |
| 部署失效 | 等待隧道注册，发布前重试 HTTP health check，记录网络/HTTP 明细并清理失败进程 | Quick Tunnel 无持久性/SLA |
| 状态丢失 | D1 保存终态 | 执行中 progress/events 在内存 |

## 4. Quick Tunnel 边界

Cloudflare Quick Tunnel 仅用于开发和验收：

- 无 SLA、无固定域名、进程结束即失效。
- 不用于生产数据、长期分享或正式客户交付。
- UI 可以展示其真实 URL，但产品和文档必须明确临时属性。
- 生产前必须替换为持久 DeploymentProvider。

## 5. 监控与告警目标

当前至少监控：

- 控制站部署健康和 Worker 5xx。
- Runner `/health` 的 `ok` 与 deployment 配置。
- 任务在各 stage 的停留时间与 failed 数量。
- Mobile Spec gate 失败、构建重试、部署健康检查失败。
- D1 delivered 数量与 Runner evidence 不一致。

生产化后增加：队列深度、lease 过期、P95 message 延迟、模型/构建成本、Runner 资源、Provider 限流和事件落库延迟。

## 6. 故障处理

- Runner 离线：控制站返回明确不可用，不创建假 job 或假 URL。
- Runner 重启：当前执行中 job 不能恢复，应标记失败后重新发起；已交付历史仍在 D1。
- Quick Tunnel 失效：历史 URL 可能不可访问；当前没有自动重部署。
- 构建失败：最多三轮真实日志修复；仍失败则终止且无 URL。
- DeploymentProvider 半成功：正式 Provider 必须按幂等键查询，禁止盲目重复创建。
- Token 疑似泄漏：立即轮换 Runner/callback/Provider token，重新发布控制站环境并审计日志。

## 7. 生产上线门禁

- Managed Cloud Runner、隔离工作区、CPU/内存/时间配额。
- 持久 job/attempt/event/checkpoint 与断线重放。
- 正式 Secret manager、轮换、最小权限和审计。
- 依赖与网络 allowlist、恶意包和供应链扫描。
- 持久 DeploymentProvider、回滚和删除能力。
- 并发、取消、重启恢复、超时、限流和半成功故障演练。
- 邀请制账户、数据导出删除、隐私与保留策略。
