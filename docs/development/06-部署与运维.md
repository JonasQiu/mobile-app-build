# 部署与运维

## 1. 区分两个部署对象

项目存在两条不同的发布链路：

| 对象 | 当前方式 | 说明 |
|---|---|---|
| SiteForge AI 控制站 | OpenAI Sites | 发布 `apps/web`，承载登录、项目和任务控制 |
| 用户生成的网站 | Cloudflare Quick Tunnel | Runner 构建后提供临时 HTTPS 验收 URL |

重新发布控制站不会自动把用户生成的网站变成持久站点。当前生成站点没有固定 URL 与 SLA。

## 2. 控制站发布前检查

```bash
cd apps/web
npm run build
npm run lint
node --test tests/*.test.mjs

cd ../..
node scripts/check-docs.mjs
git diff --check
```

发布环境需要：

- D1 `DB` binding；
- `CODEX_RUNNER_TOKEN`；
- `RUNNER_CALLBACK_TOKEN`；
- 可用的 Runner 冷启动回退地址或 D1 已登记 Endpoint；
- 身份映射所需的 Sites 配置；
- 如控制站受额外访问策略保护，Runner 自动登记所需的授权配置。

## 3. OpenAI Sites 发布流程

1. 完成 Web 构建、Lint、契约测试和必要 E2E；
2. 确认 Git 源码与准备发布的提交一致；
3. 打包 `dist`、hosting metadata 和 D1 migration；
4. 保存新 Sites 版本并部署；
5. 等待部署状态成功；
6. 验证登录入口、项目 API、D1 和 Runner 健康；
7. 保留上一可用版本用于回滚。

部署细节和环境变更应通过 Sites 托管能力完成，不在文档或脚本中写入真实凭证。

## 4. Runner 运维

当前验收 Runner 使用 macOS LaunchAgent：

- 服务名为 `com.siteforge.runner`；
- 登录后自动启动，异常退出后自动拉起；
- 环境文件权限应为 `0600`；
- Node/npm 和 `cloudflared` 使用稳定绝对路径；
- 代理与公网访问配置需要在安装时进入后台服务环境。

升级 Runner 时：

1. 阻止新任务进入；
2. 等待或暂停现有任务；
3. 更新代码与依赖；
4. 重启 LaunchAgent；
5. 检查本地 `/health`；
6. 确认新的 Runner Endpoint 已通过公网验证并登记；
7. 执行一条最小端到端任务。

## 5. Quick Tunnel 运维边界

系统当前维护两类 Quick Tunnel：

- Runner 控制 Tunnel：连接控制站与 Runner API；
- 生成站点部署 Tunnel：为单个构建结果提供临时公网 URL。

Runner 会监测进程和公网 `/health`。发生 DNS、1016、5xx 或持续不可达时，会回收旧 Tunnel、创建新地址并重新登记；部署地址轮换不会重新执行已经成功的规格、实现和构建。

Quick Tunnel 只用于开发和验收：

- 地址可能改变；
- 进程退出后地址失效；
- 没有长期可用性承诺；
- 历史 delivered 记录可以保留，但对应临时 URL 后续可能失效；
- URL 失效后需要重新执行 deployment 单步。

## 6. 故障恢复

| 故障 | 恢复方式 |
|---|---|
| 控制站版本回归 | 重新部署最近通过验证的 Sites 版本 |
| Runner 代码回归 | 停止新任务，恢复上一 Runner 版本并保留 D1 终态和本地检查点 |
| Runner 控制 Tunnel 失效 | 等待自动换址，或使用页面“修复连接”触发轮换与重派 |
| 生成网站临时 URL 失效 | 只重新执行 deployment 单步，不能承诺恢复原 URL |
| Token 轮换 | 同步更新控制站和 Runner 环境，重启 Runner 并发布新的 Sites 环境版本 |
| Runner 重启 | 重新派发任务；复用需求一致的本地成功检查点，执行中事件无法恢复 |

## 7. 生产化替换目标

进入正式对外服务前至少需要：

- 托管的隔离 Cloud Runner Pool；
- 持久 job、attempt、event、checkpoint 和 lease；
- R2 或等价共享产物存储；
- Cloudflare Pages、OpenAI Sites、Vercel 或等价持久 Deployment Provider；
- 固定域名、部署 ID、幂等查询、回滚和删除；
- Secret Manager、审计、限流、预算和资源隔离；
- 故障接管、超时回收和完整监控告警。

详细安全门禁见 [安全与运维方案](../安全与运维方案.md)。
