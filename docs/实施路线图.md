# 实施路线图

## 1. 当前基线（2026-08-15）

已完成：

- 移动端需求入口、MVP 登录、D1 项目历史。
- 历史记录点击进入详情，非进行中记录可删除。
- Runner 真实异步派发、Codex 详细执行信息、progress、message 和最近 events；控制站每 15 秒同步。
- 每用户最多 2 个进行中需求，服务端原子占位防止并发绕过。
- 运行中真实暂停；成功阶段检查点复用、显式完整重跑和四阶段单步执行。
- Mobile Spec 子阶段续跑与 Codex/构建错误上下文续修；成功单步不会重复构建。
- 步骤产物独立查看，Mobile Spec 文档按 Markdown 渲染。
- Mobile Spec Web Proposal/Specs/Design/Review/Tasks 门禁。
- Codex CLI / OpenAI Structured Outputs。
- Next.js 生成、`npm ci`、生产构建、最多三轮修复。
- 临时 DeploymentProvider、外部 HTTPS URL 和健康检查。
- 客户端防伪交付与三项 evidence。

已移除：关键词模板、健身示例、假日志、定时器假进度、内置 `/preview`、Desktop Agent。

## 2. 当前缺口

- Runner 仍依赖单机常驻；临时公网入口已支持心跳登记、失效自动换址与页面手动触发修复，但仍无 SLA。
- job、attempt、event 未持久化；checkpoint/artifact 仅保存在单机 Runner 工作区，尚无共享存储。
- Quick Tunnel URL 不持久、无 SLA。
- 缺少取消、正在运行进程的跨重启恢复、源码 ZIP、继续修改；暂停状态仍为内存协作式控制。Runner 重启后可从本地成功子阶段或失败诊断继续，但不能恢复原进程和完整事件流。
- Mobile Spec 的 iOS、Android、Harmony 全生命周期能力仍待完善。

## 3. 里程碑

### M0：真实 Web 验收链路（已完成）

一句需求可以通过 Mobile Spec、Codex、构建、部署和健康检查获得真实外部 URL；无假预览兜底。

### M1：可观察 UI（已完成）

历史详情、历史删除、六阶段百分比、Codex 详细事件、15 秒可信同步、单步快捷操作、失败步骤原地续修、Markdown 产物预览，以及 Runner 连接自动换址与“修复连接”已实现。

### M2：持久控制面（下一步）

- 新增 build_jobs、job_attempts、job_events、mobile_spec_artifacts。
- Runner 使用 lease、heartbeat、sequence 与幂等状态机。
- SSE 或游标长轮询支持断线重放。
- Runner 重启后任务恢复或明确终止。

验收：刷新、断网、Runner 重启和重复提交不丢事件、不重复付费动作。

### M3：Managed Cloud Runner

- 隔离工作区、资源限制、网络 allowlist 和并发队列。
- Secret manager、短期凭证、日志脱敏和审计。
- Artifact Store、不可变 checkpoint、源码 ZIP。
- 持久取消、暂停恢复、重试和继续修改。

验收：无需用户电脑常驻即可稳定执行，多任务相互隔离。

### M4：正式 DeploymentProvider

- 选定 Vercel、Cloudflare Pages、OpenAI Sites 或等价 Provider。
- 支持持久 deployment ID、稳定 URL、查询、重试、回滚和删除。
- 替换 Quick Tunnel，历史 URL 在 Runner 退出后仍可访问。

验收：Provider 故障、半成功和限流场景均幂等恢复。

### M5：Mobile Spec 多平台完善

- H5、iOS、Android、Harmony 全生命周期 fixtures。
- 升级降级、跨 Agent 兼容和 Schema 一致性测试。

全平台矩阵具备自动证据后发布稳定版本。

### M6：公开测试

- 邀请制账户、项目配额、预算和滥用检测。
- Session/授权管理、数据导出删除和保留策略。
- 指标告警、备份恢复、故障演练、隐私与条款。

## 4. 近期顺序

1. 持久 jobs/attempts/events 与 D1 migration。
2. Runner lease、heartbeat、恢复和 SSE。
3. 共享 Artifact/checkpoint、ZIP 与继续修改。
4. Managed Cloud Runner。
5. 正式 DeploymentProvider。

## 5. 完成定义

### 生产级 Web MVP

- 无前端伪状态或固定业务模板。
- 任务、事件、artifact 和部署均持久、幂等、可审计。
- Runner 重启、网络中断和 Provider 半成功可恢复。
- 支持取消、重试、源码下载和稳定交付 URL。
- 安全与运维门禁全部通过。

### Mobile Spec 多平台能力

- H5、iOS、Android、Harmony 每个阶段都有实现和自动证据。
- 文本、文件、URL、Agent Runtime、验证与观测使用统一协议。
- Schema、CLI、Skills 与 workflow gate 在各平台保持一致。

## 6. 暂不优先

多人协作、计费、Git 平台深度集成、模型竞价和原生 App 应建立在持久状态机、Managed Runner 和正式部署之上。
