# 独立验收浏览器执行面记录

更新日期：2026-08-24

## 1. 结论与边界

已提供可重复的 Chrome 151 / CDP 1.3 交互执行面，可稳定提供两种移动视口、触屏模拟、键盘事件、
Network/Runtime/Page 域和 Chromium Accessibility 全树。执行面采用全新临时 profile，只监听
`127.0.0.1`，不附着现有浏览器，不读取或外传凭据、Cookie、Local Storage 或用户目录。

这不是产品验收结论，也不构成放行。真实登录后的业务页面、物理触屏和真实读屏仍需独立验收专家或
人工操作补证。

没有新增 npm 包，没有修改产品组件、API、Runner、身份逻辑或用户数据。

## 3. 启动与清理

### 3.1 当前本地 production build

```bash
python3 scripts/acceptance-browser/surface.py start --local-production
python3 scripts/acceptance-browser/surface.py status
node scripts/acceptance-browser/cdp-probe.mjs
python3 scripts/acceptance-browser/surface.py stop
```

本地 production 服务器与 CDP 都只绑定回环地址。`stop` 会终止两个独立进程组并删除临时 profile；
实测停止后运行目录不存在，两个随机端口均不再监听。

### 3.2 线上 production 地址

```bash
python3 scripts/acceptance-browser/surface.py start
node scripts/acceptance-browser/cdp-probe.mjs
python3 scripts/acceptance-browser/surface.py stop
```

### 3.3 真实登录人工门禁

```bash
python3 scripts/acceptance-browser/surface.py start --headful
```

仅允许所有者在弹出的临时 Chrome 窗口中自行登录。任何专家或脚本不得索取、查看、复制或记录密码、
验证码、Cookie、Token 或既有浏览器 profile。登录后，验收专家通过 `status` 读取本机回环 CDP 地址，
完成复验后立即执行 `stop`。

## 5. 当前缺口和最小补证动作

### 5.1 真实登录后的 production 页面

事实：

- 新鲜未登录 Chrome 访问线上地址返回 Cloudflare 403；加载到的是访问拦截页，不是 production 应用；
- 本地 production build 可启动，但根路径 307 到 `/signin-with-chatgpt`，本地环境没有 Sites 登录页，
  最终返回 404；
- 因此本轮不能声称“真实登录数据下的当前 production 应用已加载”。

最小动作：所有者运行 headful 模式并在临时窗口自行完成普通 ChatGPT/Sites 登录，不向专家提供凭据。
登录成功后由独立验收专家复验。影响仅限该临时 profile 的本机会话数据；执行 `stop` 后删除。

若 headful 普通登录仍被 Cloudflare 拦截，需要站点所有者或管理员仅为该验收会话解除访问策略，或提供
权限最小、数据隔离的测试账号。不得复制现有浏览器 Cookie 或扩大站点数据权限。

### 5.2 物理触屏

CDP 已提供标准触屏模拟，但不等价于真实手机触控、浏览器工具栏、虚拟键盘或设备性能。若 P0 明确要求
物理触屏，最小动作是由人工在一台 320×568/390×844 等价真实设备或受控设备农场上执行同一用例；
本执行面不替代该证据。

### 5.3 真实读屏

已提供 Chromium Accessibility 全树，但没有自动声学输出，也未验证 VoiceOver 的实际朗读顺序、手势
和焦点反馈。最小动作是人工在同一 headful 临时浏览器上启用 VoiceOver 完成读屏复验。

若必须自动采集系统级读屏证据，需要单独确认后向指定自动化进程授予 macOS Accessibility 权限；若还
需要录屏，再单独授予 Screen Recording。两项权限可能看到其他前台 UI，影响高于纯 CDP，因此本轮未申请、
未扩大权限。

## 6. 独立验收交接边界

设备运维只证明执行环境和基础协议能力，不执行或判定以下产品 P0：

- 预览弹窗焦点进入、循环、Escape 返回和 Arrow 导航；
- 快速换批次竞态、加载失败与 SVG 安全失败语义；
- 选择状态一致性、确认门禁不变；
- 真实触屏与 VoiceOver 体验。

这些用例必须由独立验收专家在获得登录会话后重新执行并保留自己的证据，不能复用实现者结论，也不能
因本执行面可用而自动放行。

## 7. 运行风险与监控

- `status` 返回 `running=false` 或 `cdp_ready=false` 时，不得继续使用旧端口；先 `stop` 再 `start`；
- CDP 只允许回环访问，禁止改为 `0.0.0.0` 或公网端口；
- 不允许把临时 profile、状态文件或探测输出提交到 Git；
- 人工登录后必须在验收结束立即 `stop`；
- 若进程异常退出，下次 `start` 只会清理本工具自己的固定临时目录，不触碰其他浏览器或用户目录。
